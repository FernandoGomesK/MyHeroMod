# My Hero Academia Mod

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3647340771) | [Discord](https://discord.gg/vpvqft4y64) | [Wiki](https://terrariamods.wiki.gg/wiki/My_hero_Academia_mod)

The My Hero Academia Mod is a content mod for Terraria which adds custom skills, dynamic visual impact systems, and core Quirk mechanics to create an immersive superhero experience. The mod must be installed using tModLoader.

### Repository & Development

Note: This repository contains the latest public release of the My Hero Academia Mod and public contributions made since then. Active development, GitHub commits, and mechanic testing occur systematically. Updates are generally made to the `test-branch`; after that, they are merged with `Main` and pushed directly to the Steam Workshop.

### Bug Reports & Issues

To report a bug, please comment on the Steam Workshop page or join the community Discord and use the designated bug-reports forum. Providing your client logs and detailing whether the issue occurred in single-player or multiplayer helps resolve desyncs and errors much faster.

### Contributions & Assets

If you wish to contribute code or propose resprites for Quirks, weapons, or items, please reach out via Discord first. Reach out to **Khada Ace** to ensure your proposed changes align with the current visual style and development roadmap before submitting pull requests.
